# 探索重构测试策略归档

> 状态：历史测试基线
>
> 形成时间：2026-09-12
>
> 当前代码参考：`d7be6c6`（2026-09-24）

本目录保存探索收尾与连续选点重构开始前制定的测试切片、测试矩阵、回归范围和执行顺序。它用于解释当时如何控制重构风险，不表示其中记录的阻塞项仍是当前代码状态。

当前行为、完成状态和测试结果应依次以代码、自动化测试及最新提交为准。由于没有保存每个历史 Cycle 的独立验收记录，本归档不会追溯性地把 Cycle 标记为 `DONE`。

## 文件说明

- `behavior_slices.yaml`：按阶段拆分的可验收行为切片。
- `test_matrix.csv`：行为切片对应的测试层级、环境和最小判据。
- `test_strategy.md`：阶段 A/B/C 的原始准入和测试策略。
- `regression_scope.md`：每个阶段需要保护的回归范围。
- `cycle_backlog.yaml`：原始测试先行执行顺序，现已归档。

## 使用方式

- 调查历史设计原因时，可以用行为切片和矩阵定位原始风险。
- 新增相关功能时，应根据当前接口更新测试，而不是直接照搬旧 Gate 状态。
- 运行环境统一使用 `<workspace>` 占位符，不在仓库中记录个人目录、远程主机别名或本机绝对路径。
